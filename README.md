# WestX

A 3D open-world weird-west action game. You ride a grounded, cinematic frontier as a
posse of three — a bounty hunter, a witch and an engineer — and every real fight plays
like an anime arena brawl.

**Status:** pre-production. This repo holds the plan. There is no engine project yet;
that starts once the decisions in the roadmap are made.

## In one minute

- **World:** an original 1880s frontier built around a storm that never moves and the
  charged glass it leaves behind.
- **Classes:** bounty hunters survived the storm, witches bargain with it, engineers
  harvest it. Each fights, travels and investigates differently.
- **Combat:** lock-on duels with dashes, launches, vanishes, beam clashes, awakenings
  and cinematic ultimates, fought in the open world with no loading.
- **Loop:** take a bounty, track it, fight it, bring it in dead or alive.
- **Engine:** Unreal Engine 5.8 recommended.
- **First milestone:** a grey-box arena that proves the combat is fun before anything
  else is built.

WestX is inspired by the genre of *Bass X Machina* and uses none of its characters,
names or story.
